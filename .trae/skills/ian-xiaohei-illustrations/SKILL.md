# Ian 小黑怪诞正文配图

## 核心定位

为中文文章设计和生成 16:9 横版正文配图。不做商业插画、PPT 信息图或可爱卡通,而是把文章里的关键判断、流程、结构、状态或隐喻,变成一张清爽、怪诞、可读但不说明书的手绘解释图。

默认视觉 IP 是“小黑”:黑色实心、白点眼、细腿、空表情,认真做一件荒诞但成立的事。小黑必须参与画面的核心动作,不能只是装饰。

## 按需深读参考(本 skill 目录下,按任务读取,不要一次塞满上下文)

- `references/style-dna.md`:风格 DNA、颜色、文字、禁忌
- `references/xiaohei-ip.md`:小黑形象、性格、动作库、禁忌
- `references/composition-patterns.md`:8 种结构类型、原创隐喻三步法、反复刻规则
- `references/prompt-template.md`:单张生图英文提示词模板、改图提示
- `references/qa-checklist.md`:生成后检查、失败信号、迭代方法
- `assets/examples/`:仅作低频视觉校准,不要照抄构图、物件或标注

## 工作流

### 1. 消化正文

读用户给的正文/链接/Notion/Markdown/截图。提炼:核心观点是什么、哪些段落承担认知转折、哪些内容适合用图、哪些只适合文字。不要平均配图,优先选“认知锚点”:核心判断、两个断点、输入输出闭环、分流、前后对比、一鱼多吃、承接路径、常见坑、角色状态变化。

### 2. 先出配图策略

若用户只说“分析怎么配图/思考哪里需要配图”,先给 shot list。每张图写清楚:放在哪个段落后、主题、核心意思、结构类型、小黑在做什么、建议元素、建议中文标注词。默认 4-8 张;短文 1-3 张;长文不要轻易超过 9 张。

### 3. 单张生成

若用户明确要求“生成/输出/做图/帮我生成”,不要停下来等确认;用内置图像生成工具每张单独生成,不要把多张拼在一张里。每张图只讲一个核心结构。提示词必须包含:

- 16:9 横版中文正文配图
- 纯白背景
- 黑色手绘线稿
- 少量红色/橙色/蓝色中文手写批注
- 大量留白
- 小黑作为核心动作主体
- 禁止 PPT、商业插画、可爱卡通、复杂架构、左上角类型标题

不要复刻过往案例。每次都要从当前文章重新发明一个奇怪但成立的隐喻。

### 4. 检查与迭代

按 `references/qa-checklist.md` 检查。出现以下问题优先重生成或局部编辑:小黑只是装饰、画面太满、太像流程图/PPT、中文太多或错字严重、左上角出现“常见坑/流程图/系统架构图”等标题、画风太可爱/幼稚/死板、背景不是干净白底。

### 5. 保存交付

若在 workspace 内,把最终图存到 `assets/<article-slug>-illustrations/`,按 `01-topic-name.png` 序号命名。保留原始生成文件,不要覆盖已有资产,除非用户明确要求替换。

## 风格要点(精简)

- 纯白背景,不要纸纹/米色/阴影/渐变
- 黑色手绘线稿,细线,轻微抖动
- 大量留白,主体占 40%-60%,至少 35% 空白
- 少量中文手写批注,最多 5-8 处,每处 2-8 字
- 一张图只讲一个核心动作/结构/状态/隐喻
- 颜色:黑主体/红重点问题/橙主路径箭头/蓝补充系统状态(蓝非必用,宁少勿多)
- 绝对不要:商业插画、PPT 信息图、正式流程图、课程课件、可爱卡通、复杂架构、左上角写类型标题

## 小黑要点

- 黑色实心、白点眼、细腿、空表情
- 很认真但做的事荒诞,像低调系统操作员,冷幽默不卖萌
- 必须承担核心动作:搬运/拉线/卡断点/操作判断杆/变漏斗/切素材鱼/盖章/牵路径/举警告牌/伸手接不住/搬砖搭桥开门
- 判断标准:去掉小黑图仍完全成立,说明小黑太装饰,要重写让小黑成为动作主体

## 构图结构(选一种,别混太多)

Workflow流程 / 系统局部 / 前后对比 / 角色状态 / 概念隐喻 / 方法分层 / 地图路线 / 小漫画分镜。详细画法与原创隐喻三步法见 `references/composition-patterns.md`。

## 生图提示词模板

每张图单独生成。完整英文模板见 `references/prompt-template.md`,核心结构:Visual DNA(纯白/手绘/留白/克制)→ 小黑 IP 必须承担核心动作 → 主题 → 结构类型 → 核心意思 → 构图 → 元素 → 中文标注 → 颜色用法 → 约束(一图一结构、留白≥35%、标注≤5-8、禁标题、不复刻旧案例)。

## 输出口径

生成前策略输出要短而准。生成后交付:生成了几张、每张用途、保存路径、哪些最稳哪些可选。不要长篇解释风格理论,让图自己说话。
